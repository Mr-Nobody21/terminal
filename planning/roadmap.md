# Roadmap

The MVP phases are defined in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). The current code implements the browser workflow and shared Rust desktop shell; see [status](../status/STATUS.md) for verification limits.

Next delivery gates: generate and validate Windows/Linux installers on native runners; perform installed-package checks and manual diagram importer compatibility checks. Remote build execution and publishing require their existing authorization steps.

Backend, accounts, collaboration, cloud deployment, native VSDX and other explicitly deferred capabilities remain outside this MVP.
