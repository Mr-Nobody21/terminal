# Browser AI and requirement planning

AI is optional. Manual edits, deterministic pricing, storage, and export work without credentials or network access. Only explicit submission sends requirement text, clarification answers, assumptions, provider/region, and the service catalog to the configured endpoint. Provider calls may incur charges. Keys exist only in an adapter closure and UI memory; preferences explicitly serialize only provider, endpoint, and model.

Adapters issue browser-direct requests using documented [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [Anthropic Messages](https://platform.claude.com/docs/en/api/messages), and [Gemini generateContent](https://ai.google.dev/api/generate-content) formats. API envelopes are separately validated. Model names are user configuration, not claims of account availability. A local OpenAI-compatible endpoint may use HTTP on localhost. Hosted endpoints require HTTPS; browser CORS failures are recoverable and do not create a proxy.

The complete Zod JSON schema is embedded in the instructions; OpenAI-compatible JSON mode and Gemini JSON MIME mode request structured JSON. Every result passes local strict Zod validation. Generated proposals additionally pass the complete project reference/provenance/provider checks. One repair request is permitted after invalid JSON or semantic validation; transport failures are never repaired or retried. Requests support timeout and cancellation. Error messages never include provider response bodies or credentials.

Extraction labels user/PRD facts, proposes visible inferred assumptions, and ranks at most eight clarification questions by criticality and architecture/cost impact. Critical unknowns need an answer or an explicitly linked user assumption before architecture generation. Existing references survive extraction. Lean and Recommended replace the prior architecture only after both have passed validation; failure leaves the original project intact. AI cannot provide coordinates, prices, or export XML. Unsupported services require the canonical unsupported flag/category and remain unpriced until manually replaced.
