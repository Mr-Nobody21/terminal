# Cloud Architecture Planner MVP — Implementation Plan

## 1. Product Goal

Build a browser-first, local-first MVP that converts product requirements into:

1. structured infrastructure requirements,
2. a provider-specific architecture,
3. an editable cloud diagram using provider-native service icons,
4. a deterministic monthly cost estimate,
5. exportable artifacts.

The MVP must target effectively zero recurring platform infrastructure cost.

## 2. Non-negotiable Constraints

- No application backend in V1.
- No authentication in V1.
- No server-side project storage in V1.
- Project state lives in IndexedDB and exportable JSON.
- AI uses BYOK or a local OpenAI-compatible endpoint.
- AI may interpret requirements and propose architecture, but MUST NOT calculate prices.
- Pricing arithmetic is deterministic.
- Diagram XML/coordinates are generated by code, not by the LLM.
- Canonical architecture JSON is the source of truth.
- AWS, Azure, and GCP are the initial providers.
- Draw.io is the first-class editable export.
- Native Visio VSDX is deferred; SVG must remain Visio-importable.
- Avoid adding paid SaaS dependencies to the runtime.

Deliver:

Acceptance:
- AI is not called to calculate any numeric price.
- every price line links to the input/assumption that produced it.

## 7. Parallel Agent Workstreams

After Phase 1 stabilizes, Codex may split independent work:

A. Diagram workstream
- React Flow
- ELK
- canvas controls
- provider icons

B. Pricing workstream
- normalized pricing catalog
- deterministic calculators
- cost panel
- tests

C. AI/requirements workstream
- AI adapters
- prompt schemas
- requirement extraction
- clarification ranking

D. Export workstream
- Draw.io XML
- SVG/PDF/DOCX/Markdown

Rules:
- Do not parallelize changes to the canonical schema without coordination.
- Canonical model changes land before dependent branches.
- Each workstream must add tests.
- Merge one workstream at a time and run the full check suite.

## 8. Definition of Done for MVP

A user can:

1. open the static web app,
2. paste a product description or PRD,
3. configure their own AI key or local endpoint,
4. answer relevant questions,
5. choose AWS/Azure/GCP and a region,
6. generate Lean and Recommended architectures,
7. see cloud-native service icons,
8. edit resources and connections,
9. see cost recalculate deterministically,
10. inspect assumptions,
11. export Draw.io, JSON, SVG, PDF, Markdown, and DOCX,
12. close/reopen the browser and retain local projects.
